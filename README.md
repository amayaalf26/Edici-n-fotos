# Edición de fotos para historias

1. Pon la foto en `originales/` y agrégala a `estilo.json` (recorte y modo `papel` o `pantalla`).
2. `python editar.py` (o `python editar.py nombre.jpg`).
3. El resultado queda en `salida/*_historia.jpg` (1080x1920, listo para subir a historias).

Requiere: `pip install opencv-python-headless numpy`
